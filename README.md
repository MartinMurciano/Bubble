# 🎟 Bubble

Plataforma centralizada para la gestión y comercialización de eventos.

## 🚀 Tecnologías

- Frontend: React.js
- Backend: Node.js + Express
- Base de datos: MySQL
- Arquitectura: Arquitectura en capas + Microservicios
- Contenedores: Docker

## 👥 Roles del sistema

- Administrador
- Organizador
- Cliente

## 📂 Documentación

La documentación completa del proyecto se encuentra en la carpeta `/docs`.
